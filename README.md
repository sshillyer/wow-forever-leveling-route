# WoW Forever Leveling Route

Undead-start Horde leveling route for WoW Forever, 1–60: questing zones by level with the best window for each dungeon and its Horde quests.

- `index.html` – the route overview.
- `dungeons/` – one page per dungeon with bosses, loot and quests.

Pages are plain HTML with no build step. Hosted on GitHub Pages, item and quest links get Wowhead hover tooltips; anywhere that blocks Wowhead's script (such as a Claude artifact) they stay plain links to Wowhead.
